# Shape Portals (Forge 1.20.1)

Порталы Незера произвольной формы (обсидиан / плачущий обсидиан) и зеркальная генерация в другом измерении.

## Получить jar
**A. GitHub Actions (проще всего):** создайте репозиторий, залейте содержимое папки,
вкладка Actions -> Build mod -> артефакт `shapeportal-jar`.

**B. Локально** (JDK 17 + Gradle 8.1.1): `gradle build`
-> `build/libs/shapeportal-1.20.1-1.0.0.jar` -> в папку `mods/` (Forge 47.x).

## Как работает
* Зажигание: ПКМ огнивом/огненным шаром по любой замкнутой рамке (flood-fill в плоскости X или Z, до 1024 клеток, до 40x40).
* Телепорт: миксин запоминает исходный портал; в `PortalForcer.createPortal` рамка копируется (форма, ось, тип блоков рамки).
* Координаты: ванильные X/8, Z/8; ищется лучшее место в радиусе 16 (минимум разрушаемых блоков), рельеф вырезается.
* Связывание: ставятся обычные `nether_portal` блоки, поэтому POI и поиск существующих порталов работают как в ваниле.
